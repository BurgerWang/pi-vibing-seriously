# Benchmark and return attribution

## Benchmark alignment

The benchmark must share the strategy's:

- period and frequency;
- return convention (total return vs price return);
- rebalance timing (where applicable);
- universe scope, or be accompanied by an exposure report that explains
  the differences.

A mismatched benchmark makes every comparison meaningless — the excess
return will include the mismatch, not the strategy.

## Attribution

Decompose the excess return (strategy − benchmark) into:

- **Selection effect** — does the strategy pick names that outperform
  within the same groups?
- **Exposure effect** — does the strategy differ from the benchmark in
  industry or market-cap exposure, and did those differences pay?
- **Timing/other effect** — rebalance timing differences, cash drag,
  residual.

Methods vary by project (single-period vs multi-period attribution,
Brinson-style vs regression-based); the requirement is the same: the
components must reconcile with the reported excess return.

## Reporting

- Report attribution for the whole period AND per sub-period/regime.
- Report exposure drift: how far the portfolio drifted from its target
  exposures between rebalances.
- If attribution cannot be computed, say so and report the exposure
  differences instead — a strategy whose edge is an industry tilt should
  be labeled as such.
