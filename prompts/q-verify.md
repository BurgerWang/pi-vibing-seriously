# Verify

Claims: $ARGUMENTS — or the last completed work when omitted.

Use `skill:validation-ladder`. Stay read-only and use declared recipes in
VERIFY mode. Group related claims when one check proves them; do not create
ceremonial gates per sentence. Report only PASS, FAIL, BLOCKED, or NOT_RUN
with the exact supporting check. A full suite is appropriate only when the
claim is product-wide, cross-cutting, a declared release gate, or explicitly
requested.
