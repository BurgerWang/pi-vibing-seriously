# Review

Scope: $ARGUMENTS — or the current implementation when omitted.

Use `skill:repository-audit` in read-only mode. Inspect logic, boundary and
error paths, tests, compatibility, and omissions. Lead with actionable
findings ordered by severity and backed by tight file/line evidence. Separate
confirmed defects from risks needing more evidence, state review coverage,
and say explicitly when no material finding is found. Do not apply fixes.
