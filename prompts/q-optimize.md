# Optimize

Target: $ARGUMENTS

For engineering work, use `skill:implementation-workflow`: capture a relevant
baseline, change the smallest causal factor, repeat the same measurement, and
verify preserved behavior with affected tests plus one proportionate final
check.

For a quantitative experiment, use `skill:quant-research-design` to freeze
the objective, parameter space, segmentation, adoption rule, and appropriate
specialist route before results. Preserve all trials and require
out-of-sample or walk-forward evidence; do not report only the best trial.

Report comparable before/after measurements, correctness evidence, limits,
and whether the result is causal, observational, or still uncertain.
